Update the project roadmap after completing work.

## Steps
1. Read `apps/superadmin/app/data/roadmap.ts`
2. Find or create the relevant entry in `RAW_FEATURES`
3. Update fields: `name`, `category`, `percentage`, `lastModifiedBy`, `lastModifiedDate`
4. Set `phase` appropriately: `development` / `testing` / `deployment` / `operations`
5. Follow the full guide at `docs/update-project-progress-guide.md`
