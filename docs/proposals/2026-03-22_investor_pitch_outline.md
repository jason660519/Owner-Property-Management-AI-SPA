# Investor Pitch Outline - Owner AI Platform

建立日期：2026-03-22
版本：v1
用途：募資簡報大綱

## 1. 一句話定位

Owner AI 是一個不動產交易與租賃服務協作平台，讓房東、租客、買家、仲介、代書、律師、裝修團隊與履約合作方在同一個工作流中完成案件協作。

## 2. 市場問題

1. 不動產交易與租賃流程高度碎片化
2. 房東、買家、租客、仲介、代書、律師與銀行之間使用不同工具
3. 資訊斷裂造成跟進延遲、文件錯誤、溝通成本高、成交效率低
4. 多數工具只服務單一角色，無法形成真正的跨角色協作網絡

## 3. 解決方案

1. 免費流量入口：自售房東、自租房東、租客、買家
2. 付費專業工作台：仲介、店長/老闆、代書、律師、裝修團隊、履保合作方
3. AI 協作：OCR、文件摘要、跟進提醒、任務節點、角色切換與流程追蹤
4. 商業模式：免費導流 + 按案件/分店收費 + 企業合作方案

## 4. 為什麼現在做

1. AI 已經足以降低文件整理與溝通追蹤成本
2. 不動產專業角色對數位化工具的接受度提升
3. 台灣與澳洲都存在大量中小型房東、仲介團隊與專業合作方
4. 市場目前多為單點工具，尚未出現強勢的跨角色協作平台

## 5. 產品架構

### 免費角色

1. 自售房東
2. 自租房東
3. 租客
4. 買家

### 付費角色

1. 仲介個人版
2. 分店管理版
3. 代書 / 律師 / 裝修團隊按案件收費
4. 履約保證銀行與大型合作方企業版

## 6. 營收模型

1. 仲介個人版：按案件或月費
2. 分店管理版：按分店、席次、案件量
3. 代書 / 律師 / 裝修：按案件或按專案
4. 企業合作版：年度合約與 API 整合
5. 長期延伸：支付、電子簽署、保險、履保分潤

## 7. 初步價格帶

### 台灣

1. 仲介個人版：每月 NT$1,500 - NT$3,000 或每案件 NT$300 - NT$800
2. 分店管理版：每月 NT$6,000 - NT$15,000
3. 代書：每案件 NT$500 - NT$1,500
4. 律師：每案件 NT$1,500 - NT$5,000
5. 裝修團隊：每專案 NT$500 - NT$2,000

### 澳洲

1. 仲介個人版：每月 AUD 69 - AUD 129 或每案件 AUD 12 - AUD 25
2. 分店管理版：每月 AUD 249 - AUD 599
3. 代書 / conveyancing：每案件 AUD 20 - AUD 60
4. 律師：每案件 AUD 60 - AUD 180
5. 裝修團隊：每專案 AUD 20 - AUD 80

## 8. Go-to-Market

### Phase 1

1. 用免費房東工具取得案件供給
2. 用免費租客/買家入口取得需求
3. 驗證案件資料完整度與活躍度

### Phase 2

1. 對仲介個人版收費
2. 對店長與分店導入團隊版
3. 驗證案件協作對成交率的影響

### Phase 3

1. 引入代書、律師、裝修團隊
2. 建立平台生態收入
3. 推進企業合作版

## 9. 核心指標

1. 每月新增案件數
2. 免費角色月活躍數
3. 付費專業角色數
4. 每月 ARPU
5. 免費案件轉付費協作比率
6. 跨角色協作完成率
7. 付費角色留存率

## 10. 投資敘事重點

1. 不是做單一房東工具，而是在做多角色工作流平台
2. 免費角色負責供給與需求，付費角色負責營收
3. 平台天然適合擴張到支付、簽署、保險與履保合作
4. 一旦案件與協作關係留在平台，轉換成本會提高
