# 台灣不動產買賣交易流程

本文描述一般台灣不動產買賣交易中，買方、仲介、賣方與 **Owner AI**、價金信託、特約金融、特約地政士之間的責任與流程關係。

---

## 一、流程主軸：買方 → 仲介 → 賣方

### 買方（買方）

1. 購屋條件提出  
2. 電腦連線售屋資訊、購屋條件配對  
3. 房屋解說、參觀現場  
4. 買賣條件確定、支付定金  
5. 正式簽約並支付房屋買賣頭款  
6. 繳納契稅  
7. 辦理貸款  
8. 房地點交並支付尾款取得產權  

### 房屋仲介公司（房屋仲介公司）

1. 免費行情估價、銷售企畫報告  
2. 進行產權調查、製作產權七審說明書  
3. 進行廣告活動  
4. 代收定金  
5. 辦理雙方簽訂買賣契約事宜  
6. 辦理雙方用印、完稅  
7. 產權移轉過戶、貸款辦理  
8. 約妥雙方辦理房地點交  
9. 售後服務  

### 賣方（賣方）

1. 售屋條件提出  
2. 簽訂專任委託銷售契約書  
3. 瞭解銷售情況  
4. 買賣條件確定、收取定金  
5. 正式簽約並收取房屋買賣頭款  
6. 繳納土地增值稅  
7. 賣方塗銷貸款  
8. 房地點交並收取尾款  

---

## 二、中央協力：Owner AI、價金信託、特約金融、地政士

### Owner AI

- **委託銷售（與賣方）**  
  - 代繳納稅款  
  - 代清償原貸款  
  - 售屋款撥付  

- **委託承買（與買方）**  
  - 各期購屋款  
  - 銀行貸款或代償餘額  

### 不動產買賣價金信託客戶

- 擔任買賣價金信託中介，與 **Owner AI**、賣方、特約金融連結，收付與不動產買賣價金相關款項。

### 特約金融

- 與不動產買賣價金信託客戶配合。  
- **核發信託履約保證書、買方權利義務履行認證**（與買方連結）。  
- 受理買方之**銀行貸款申請作業**。

### 特約地政士

- 受特約金融**專屬委任**。  
- **產權調查、用印、繳稅、塗銷原設定**（與賣方流程連結）。  
- **核發信託履約保證書、賣方權利義務履行認證**（與賣方連結）。

### 產權移轉登記

- 買方流程與賣方流程中與「產權移轉過戶／點交」相關步驟，皆匯整至**產權移轉登記**，由特約地政士與特約金融等協力完成登記與款項交付。

## 三、流程圖對照說明

| 角色 | 主要職責 |
|------|----------|
| 買方 | 提出條件、看屋、簽約、付款、完稅、貸款、點交取得產權 |
| 房屋仲介公司 | 估價、產調、廣告、代收定金、簽約、用印完稅、過戶與貸款辦理、點交、售後服務 |
| 賣方 | 委託銷售、收定金與頭款、完稅、塗銷貸款、點交收尾款 |
| **Owner AI** | 委託銷售端：代繳稅、代清償原貸款、售屋款撥付；委託承買端：各期購屋款、貸款或代償餘額 |
| 不動產買賣價金信託客戶 | 價金信託收付、與 Owner AI／賣方／特約金融連動 |
| 特約金融 | 信託履約保證、買方權利義務認證、貸款申請作業 |
| 特約地政士 | 專屬委任、產權調查、用印繳稅塗銷、賣方權利義務認證、產權移轉登記 |
