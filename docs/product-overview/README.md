## 🎯 快速理解產品

### 產品定位

**房東物件管理語音 AI App** 是一個專為房東設計的智慧物業管理平台，透過 AI 語音助理協助房東高效處理房屋出租、出售與持有期間的各項管理工作。

### 雙端應用架構

本產品採用 **Monorepo 架構**，包含兩個互補的應用端：

#### 🌐 公司官網 (Next.js Web App)
- **位址**: `http://localhost:3000`
- **用途**: 產品介紹、會員註冊、多用戶登入入口
- **適用**: 桌面與平板瀏覽器
- **技術**: Next.js 16 + React 19 + TypeScript

#### 📱 房東管理 App (Expo Mobile App)
- **位址**: `http://localhost:8081` (開發環境 Web 預覽)
- **用途**: AI 語音助理、物件管理、租客篩選、財務報表
- **適用**: iOS / Android 原生 App + Web 瀏覽器
- **技術**: Expo 54 + React Native 0.81 + TypeScript

### 目前開發狀態

#### ✅ 已完成功能

**Web 端**:
- 基礎官網架構與設計系統
- 登入/註冊頁面
- Header 導航元件
- Supabase SSR 整合

**Mobile 端**:
- 登入/註冊/歡迎頁面
- 儀表板框架（側邊欄 + 底部導航）
- 角色切換邏輯（房東/超級管理員）
- 響應式設計（Web + Mobile 雙模式）

#### ⚠️ 開發中功能

- AI 語音助理互動介面
- 物件管理與行銷頁面生成
- 租客篩選與合約製作
- 維修通報系統
- 財務報表功能

## 💡 常見問題

### Q1: 為什麼要分成 Web 和 Mobile 兩個應用？

**A**: 
- **Web 端**：作為產品門戶，提供完整的產品資訊與註冊流程，適合初次接觸的用戶
- **Mobile 端**：專為房東日常管理設計，提供隨時隨地的物件管理能力與 AI 語音助理

兩者互補，Web 端負責「獲客」，Mobile 端負責「服務」。

### Q2: Mobile App 為什麼可以在瀏覽器打開？

**A**: Expo 支援 React Native for Web，可以將 React Native 程式碼編譯成網頁版本。這主要用於：
- 開發測試（無需實體裝置）
- 快速原型展示
- 提供輔助訪問管道

但主要使用場景仍是 iOS/Android 原生 App。

### Q3: 兩端應用如何共用程式碼？

**A**: 透過 Monorepo 架構：
- 共用 TypeScript 型別定義
- 共用業務邏輯函數
- 共用設計系統（Tailwind CSS）
- 共用後端服務（Supabase）

未來會建立 `packages/ui` 共用 UI 元件庫。

### Q4: 目前可以測試哪些功能？

**A**: 
- ✅ 登入/註冊流程（雙端）
- ✅ 儀表板框架與導航（Mobile）
- ✅ 角色切換（Mobile）
- ⚠️ AI 語音助理（開發中）
- ⚠️ 物件管理（開發中）
