## 1. 產品願景

建立一個專門為房東設計的房屋管理 AI 語音 App，透過自然語言對話，協助房東高效率處理房屋**出租、出售與持有期間管理**及相關財稅問題，降低物業管理與租賃合約管理的複雜度。

## 2. 產品 Landing Page 與註冊流程

本產品僅提供給**實際不動產所有權人或其合法授權代理人（如代管公司、會計師事務所）**使用，所有帳號申請皆以房東身分為核心設計。

公司產品的 Landing Page 分為左右兩區塊：

- **右邊**：公司產品介紹與價值主張。
- **左邊**：會員註冊與登錄功能。

### 註冊機制

提供多種便捷註冊方式：

1.  **手機註冊**：手機號碼 + 手機驗證碼。
2.  **社群帳號註冊**：Google / Facebook 等主流社交軟體帳號 + 手機驗證碼驗證。
3.  **Email 註冊**：Email + 手機驗證碼驗證。

### 登入機制

- **帳號 (Email) + 手機驗證碼登入**，未來可擴充雙重驗證（2FA），以提高房東後台登入之安全性。

## 3. 技術架構與平台

本產品採用 **Monorepo 架構**，包含兩個主要應用端，分別針對不同使用場景與裝置優化：

### 3.1 公司官網 (Next.js Web App)

- **技術框架**：Next.js 16 (App Router) + React 19 + TypeScript
- **訪問位址**：`http://localhost:3000` (開發環境)
- **主要功能**：
  - 產品介紹與價值主張展示
  - 多用戶登入入口（房東、超級管理員）
  - 會員註冊與身分驗證
  - 響應式設計，適配桌面與平板瀏覽器
- **定位**：作為產品的門戶網站，提供完整的產品資訊與註冊登入流程，適合初次接觸產品的潛在用戶

### 3.2 房東管理 App (Expo Mobile App) ⏸️ (開發已暫緩)

- **技術框架**：Expo 54 + React Native 0.81 + TypeScript + NativeWind ⏸️ (已暫緩)
- **訪問位址**：`http://localhost:8081` (開發環境 Web 預覽模式) ⏸️ (已暫緩)
- **主要功能**：
  - AI 語音助理互動介面
  - 房東物件管理儀表板
  - 文件上傳與管理
  - 租客篩選與合約製作
  - 維修通報處理
  - 財務報表查詢
- **支援平台**：
  - iOS / Android 原生 App（主要使用場景）
  - Web 瀏覽器（開發測試與輔助訪問）
- **定位**：專為房東日常管理需求設計的行動應用，提供隨時隨地的物件管理能力

### 3.3 技術架構特色

- **共用後端**：兩端應用皆使用 Supabase 作為統一的後端服務（資料庫、身分驗證、儲存）
- **設計系統統一**：採用 Tailwind CSS 確保雙端視覺風格一致
- **開發效率**：Monorepo 架構允許共用型別定義、工具函數與業務邏輯
- **漸進式開發**：Web 端提供快速原型驗證，Mobile 端提供完整的原生體驗
