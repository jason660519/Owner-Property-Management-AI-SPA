# CodeX（OpenAI）SDK 資源整理

來源：
- https://platform.openai.com/docs/libraries
- https://github.com/openai/openai-python

## 1) 官方 SDK

| 語言 | 套件 | 安裝 | 官方文件 / Repo |
|---|---|---|---|
| Python | `openai` | `pip install openai` | https://platform.openai.com/docs/libraries / https://github.com/openai/openai-python |
| Node.js (TS/JS) | `openai` | `npm i openai` | https://platform.openai.com/docs/libraries |

認證（常用）：
- `OPENAI_API_KEY`（環境變數）

## 2) HTTP / REST

若不想用 SDK，也可直接走 HTTP（任意語言皆可）。入口與完整參考以官方文件為準：
- https://platform.openai.com/docs/libraries
