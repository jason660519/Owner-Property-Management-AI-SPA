三、測試策略

公司頁面：使用 Playwright 進行 E2E 測試，並整合 Lighthouse CI 監控 Core Web Vitals，設定退化警報（LCP 劣化 > 20% 時告警）。
第三方 API 整合：先以 MSW（Mock Service Worker）模擬 API 回應進行快速單元測試，再於 Staging 環境連真實沙盒 API 執行整合測試。
