## 三、測試策略

已完成功能：補齊 E2E 自動化測試（Playwright），目標覆蓋儀表板、物件新增（手動+OCR）完整流程。

新開發功能：遵循 TDD 流程—先撰寫測試（紅燈），再實作功能（綠燈），再重構（整理）。

AI 功能測試：使用 Mock LLM 回應進行單元測試，以真實 API 進行整合測試（限 CI 環境執行）。
