一、覆蓋功能範圍

本文件涵蓋以下尚未完成開發的超級管理員功能，提供測試規劃藍圖：

  • 超級管理員-網站行為監控與紀錄功能

  • 超級管理員-網站效能監控功能

二、測試策略

單元測試：各功能的 Server Actions（角色CRUD、配額計算、異常偵測邏輯）需達 80% 以上覆蓋率。
整合測試：Supabase RLS 策略驗證（確保非 super_admin 角色無法存取敏感端點）。
E2E 測試（Playwright）：以 super_admin 帳號登入，驗證各管理功能的完整操作流程。
