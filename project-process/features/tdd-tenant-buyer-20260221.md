## 三、測試策略

儀表板功能（90%）：補齊 Playwright E2E 自動化測試，確保數據顯示與路由跳轉正確。

即時通訊功能：需要 WebSocket/SSE Mock 環境，先以 Unit Test 驗證訊息狀態邏輯，再進行整合測試。

財務功能：金額計算邏輯需有 Unit Test，逾期邏輯需測試邊界條件（剛好到期當天）。
