二、測試策略

認證系統（90%）：補齊 Playwright E2E，自動化驗證 Token 過期流程與 OAuth 完整路徑。
OCR/上傳功能（95%）：整合測試使用真實 Supabase Storage 測試環境，驗證端到端上傳與擷取流程。
待開發功能：遵循 TDD 流程，先撰寫失敗測試，再實作功能使測試通過。

三、E2E 自動化目標（Playwright）

  • 認證流程：Email 登入 → 首頁重定向（已完成）
  • 密碼重設：申請重設 → 收信 → 重設密碼 → 舊 Session 失效（待補）
  • 照片上傳：選擇20張 → 上傳進度條 → 縮圖顯示 → 設定封面（待補）
  • OCR 流程：上傳謄本 → 擷取結果顯示 → 人工校正 → 保存（待補）
