一、租客功能測試清單

#功能進度測試描述類型狀態
T-01租客(已簽約)-儀表板90%顯示租約到期日、下次繳費截止日與金額E2EPASS（手動）
T-02租客(已簽約)-儀表板90%快速入口（維修申請、溝通中心）點擊正確跳轉E2EPASS（手動）
T-03租客(潛在)-儀表板90%可在此頁面發起看房預約，系統記錄並通知房東整合PASS（手動）
T-04租客(潛在)-儀表板90%推薦物件依瀏覽偏好排序，不顯示已查詢過的物件Unit待補
T-05維修申請0%送出維修申請後，房東端即時顯示新申請通知整合待開發
T-06維修申請0%緊急維修標記後，10 分鐘內通知送達房東整合待開發
T-07溝通中心0%傳送圖片附件（10MB），接收方正確顯示E2E待開發
T-08繳費記錄0%逾期費用顯示逾期天數與累計罰款，醒目標示E2E待開發
T-09繳費記錄0%下載單筆收據 PDF，格式正確（金額、日期、付款方式）整合待開發

二、買家功能測試清單

#功能進度測試描述類型狀態
T-10買家(已簽約)-儀表板50%顯示合約進度時程表（簽約→履約→過戶→交屋）各階段標示E2E部分完成
T-11買家(已簽約)-儀表板50%待辦事項（需簽文件）顯示正確數量E2E部分完成
T-12買家的溝通中心0%發送 PDF 附件，訊息顯示已讀回條E2E待開發
T-13買家的繳費記錄0%年度付款總額統計與圖表顯示正確Unit待開發
T-14買家的繳費記錄0%未付款項目顯示到期日，超期後醒目標示E2E待開發

三、測試策略

儀表板功能（90%）：補齊 Playwright E2E 自動化測試，確保數據顯示與路由跳轉正確。
即時通訊功能：需要 WebSocket/SSE Mock 環境，先以 Unit Test 驗證訊息狀態邏輯，再進行整合測試。
財務功能：金額計算邏輯需有 Unit Test，逾期邏輯需測試邊界條件（剛好到期當天）。
