# 多角色不動產 AI 平台商業計畫

建立日期：2026-03-22
最後更新：2026-03-22
適用市場：台灣、澳洲
文件類型：Business Plan / Pricing Strategy / GTM Draft

## 1. 背景與問題重定義

本專案原本以「服務自售房東、自租房東」為主，但產品演進後已具備多角色平台特徵，實際可服務的對象已擴大到：

1. 自售房東
2. 自租房東
3. 租客
4. 買家
5. 仲介個人（不動產營業員、不動產經紀人）
6. 房仲店長與老闆
7. 過戶代書
8. 律師
9. 裝潢工人與裝修團隊
10. 履約保證銀行或履保合作方

因此，產品定位不應再只是房東工具，而應正式調整為：

不動產交易與租賃服務協作平台

平台的核心價值不是單點功能，而是把「找房、看房、洽談、簽約、過戶、履約、交屋、維修、裝修」等流程放在同一個協作環境中完成。

## 2. 新的商業定位

### 2.1 平台定位

一個服務房東、租客、買家、仲介、代書、律師、裝修團隊與履保合作方的不動產 AI 協作平台。

### 2.2 商業模式總結

平台採雙引擎模式：

1. 免費流量引擎：自售房東、自租房東、租客、買家
2. 專業付費引擎：仲介、房仲店長/老闆、代書、律師、裝修團隊、履約保證銀行

### 2.3 收費原則

初期不收費角色：

1. 自售房東
2. 自租房東
3. 租客
4. 買家

初期收費角色：

1. 仲介個人
2. 房仲店長與老闆
3. 過戶代書
4. 律師
5. 裝潢工人與裝修團隊
6. 履約保證銀行

### 2.4 核心營收邏輯

1. 先用免費角色累積案件與需求
2. 再讓付費專業角色承接案件、協作處理並付費使用平台
3. 長期加上企業合作、加值服務與分潤收入

## 3. 目標客群與優先順序

### 3.1 第一階段流量入口

1. 自售屋主
2. 自租屋主

這兩類使用者是案件供給的來源，也是平台最容易低成本取得的核心流量。

### 3.2 第一階段主要付費客群

1. 仲介個人
2. 房仲店長與老闆

理由：

1. 直接面向成交與佣金收入
2. 有明確的案件管理痛點
3. 較容易接受按案件或按物件的收費模型
4. 能快速驗證平台是否能提升成交效率與團隊管理效率

### 3.3 第二階段延伸付費客群

1. 過戶代書
2. 律師
3. 裝修團隊

### 3.4 第三階段企業合作客群

1. 履約保證銀行
2. 大型房仲品牌
3. 保險、支付、電子簽署合作方

## 4. 角色服務設計

## 4.1 自售房東

### 核心價值

讓房東免費完成刊登、詢問整理、看屋安排、文件整理與交易流程追蹤。

### 服務項目

1. 物件刊登與管理
2. AI 物件文案與介紹輔助
3. 詢問與預約看屋整合
4. 文件上傳與進度追蹤
5. 基本交易或簽約任務清單

### 定價策略

免費

### 補充

高成本 AI 功能需限制配額，例如 OCR、批量文案生成、進階 AI 協作。

## 4.2 自租房東

### 核心價值

讓房東免費管理出租流程、租客詢問、租約任務與維修節點。

### 服務項目

1. 出租物件管理
2. 租客詢問與篩選入口
3. 預約看房與申請管理
4. 租約任務與提醒
5. 基本維修追蹤

### 定價策略

免費

## 4.3 租客

### 核心價值

讓租客用同一入口完成找房、申請、看屋、簽約、維修與付款紀錄管理。

### 服務項目

1. 找屋與收藏
2. 看屋預約
3. 申請資料提交
4. 合約與文件入口
5. 維修申請與通知

### 定價策略

免費

## 4.4 買家

### 核心價值

讓買家用同一入口完成看房、出價、文件提交、簽約與交屋任務追蹤。

### 服務項目

1. 找房與收藏
2. 看屋管理
3. 出價與洽談流程追蹤
4. 文件清單與合約入口
5. 交屋前待辦與通知

### 定價策略

免費

## 4.5 仲介個人

### 核心價值

提供案件 CRM、客資管理、AI 跟進、流程協作與成交節點可視化。

### 服務項目

1. 案件與客資管理
2. AI 跟進建議與提醒
3. 帶看、出價、簽約節點追蹤
4. 與房東、買家、租客、代書的跨方協作
5. 文件與任務清單管理

### 定價策略

按案件或按物件收費為主，後續可升級月費方案。

### 建議價格帶

台灣：

1. 每活躍案件 NT$300 到 NT$800
2. 或每月 NT$1,500 到 NT$3,000，含固定案件額度

澳洲：

1. 每活躍案件 AUD 12 到 AUD 25
2. 或每月 AUD 69 到 AUD 129，含固定案件額度

## 4.6 房仲店長與老闆

### 核心價值

提供分店案件池、名單分派、團隊管理、轉化率分析與 SOP 稽核。

### 服務項目

1. 分店與團隊儀表板
2. 案件分派與進度總覽
3. 成交率、帶看率、跟進率分析
4. 角色與權限管理
5. 多角色協作紀錄與管理視圖

### 定價策略

按分店加案件量收費。

### 建議價格帶

台灣：

1. 每分店每月 NT$6,000 到 NT$15,000
2. 超額席次或超額案件另加價

澳洲：

1. 每分店每月 AUD 249 到 AUD 599
2. 超額席次或超額案件另加價

## 4.7 過戶代書

### 核心價值

讓代書更有效率管理文件、過戶進度與跨方協作。

### 服務項目

1. 案件接收與狀態管理
2. 過戶文件清單與補件提醒
3. 簽約、過戶、交屋節點管理
4. 與買賣雙方、仲介、銀行的協作入口

### 定價策略

按案件收費。

### 建議價格帶

台灣：每案件 NT$500 到 NT$1,500

澳洲：每案件 AUD 20 到 AUD 60

## 4.8 律師

### 核心價值

讓律師以標準化流程處理契約審閱、風險標記與爭議支援。

### 服務項目

1. 契約審閱
2. 條款風險提示
3. 爭議處理紀錄
4. 文件版本與批註管理

### 定價策略

按案件或按審閱次數收費。

### 建議價格帶

台灣：每案件 NT$1,500 到 NT$5,000

澳洲：每案件 AUD 60 到 AUD 180

## 4.9 裝潢工人與裝修團隊

### 核心價值

讓裝修團隊從平台接案、回報進度、管理報價與驗收。

### 服務項目

1. 接收案件與 lead
2. 報價與工期安排
3. 施工照片回報
4. 驗收節點與付款里程碑記錄

### 定價策略

按專案收費，或按有效 lead 收費。

### 建議價格帶

台灣：

1. 每專案 NT$500 到 NT$2,000
2. 或每 lead NT$100 到 NT$300

澳洲：

1. 每專案 AUD 20 到 AUD 80

## 4.10 履約保證銀行

### 核心價值

讓銀行或履保合作方取得案件透明度、資金節點與文件追蹤能力。

### 服務項目

1. 案件節點監控
2. 文件審核與追蹤
3. 資金里程碑管理
4. 風險事件提醒
5. API 或企業整合

### 定價策略

不建議做標準公開售價，採企業合作客製報價。

## 5. 定價架構

## 5.1 定價層級

### 免費層

適用：自售房東、自租房東、租客、買家

內容：

1. 基本刊登與案件管理
2. 基本文件上傳與進度追蹤
3. 基本訊息與提醒
4. 基本 AI 助理能力

### 專業案件層

適用：仲介個人、代書、律師、裝修團隊

內容：

1. 案件協作
2. 文件節點追蹤
3. 跨角色流程管理
4. AI 工作輔助

計費方式：按案件或按物件

### 團隊管理層

適用：房仲店長、房仲老闆

內容：

1. 分店管理
2. 團隊席次
3. 業績分析
4. 案件分配
5. SOP 與權限控管

計費方式：按分店、席次、案件量

### 企業合作層

適用：履保銀行、大型房仲品牌、合作通路

內容：

1. API 整合
2. 專屬報表
3. 合規與稽核流程
4. 導入與客製支援

計費方式：年度合作或客製報價

## 5.2 定價原則

1. 免費角色追求案件量與活躍度
2. 付費角色追求成交效率與協作價值
3. 高成本 AI 功能必須有限額或加購
4. 台灣與澳洲共用商業邏輯，但價格帶分開

## 6. 12 個月落地路線

## 6.1 Phase 1：流量驗證期（0 到 3 個月）

目標：建立免費入口與案件池

重點：

1. 強化自售房東、自租房東免費工具
2. 強化租客與買家入口
3. 建立案件、文件、看屋、訊息、進度追蹤基礎流程

核心 KPI：

1. 月新增案件數
2. 月活躍房東數
3. 月活躍租客與買家數
4. 案件資料完整度

## 6.2 Phase 2：專業變現期（3 到 6 個月）

目標：開始向仲介與店長收費

重點：

1. 上線仲介個人版
2. 上線分店管理版
3. 建立案件分派、追蹤、分析、協作能力

核心 KPI：

1. 付費仲介數
2. 付費分店數
3. 每案件平均收入
4. 免費案件轉付費協作案件比例

## 6.3 Phase 3：服務擴張期（6 到 12 個月）

目標：把案件延伸到代書、律師、裝修與企業合作方

重點：

1. 上線代書與律師協作包
2. 上線裝修 lead / 工單能力
3. 啟動銀行或履保合作方案

核心 KPI：

1. 每月合作案件數
2. 每案件附加收入
3. 跨角色協作完成率
4. 專業角色留存率

## 7. 官網與產品對齊建議

原本如果官網仍以房東工具為主，應改成平台敘事：

1. 免費給房東、租客、買家使用
2. 付費給專業角色使用
3. 主打跨角色協作、成交效率與流程透明化

## 7.2 pricing page 第一版資訊結構

1. 免費方案：房東 / 租客 / 買家
2. 仲介個人版
3. 分店管理版
4. 專業服務合作版
5. 企業合作版
6. FAQ：為何房東免費、如何計價、台灣與澳洲如何切換、AI 配額如何計算

1. 重新定義官網首頁文案，不再只服務房東
2. 建立 pricing page 的正式方案內容
3. 為仲介個人與房仲店長定義明確功能包

## 9. 結論

本專案接下來的成長方向，不應是把更多功能堆到房東端，而是把房東、租客、買家帶來的案件流量，轉化為仲介、店長、代書、律師、裝修與企業合作的付費協作生態。

短期重點是：

1. 房東免費入口做大
2. 仲介與店長先收費
3. pricing page 與官網敘事同步改版

中期重點是：

1. 擴張專業服務角色
2. 形成多角色案件協作網絡
3. 讓平台從工具變成交易與服務入口
