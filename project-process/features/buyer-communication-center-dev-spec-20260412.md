# 買家的溝通中心 Dev Spec（Row 012）

- 日期：2026-04-12
- 對應 Row：012
- 功能名稱：買家的溝通中心
- 路由：`/buyer/contracted/communication`

## 目標

為已簽約買家提供可用的溝通中心 MVP，支援以下核心能力：

1. 與房東/仲介瀏覽與回覆訊息
2. 顯示訊息已讀/未讀狀態（已讀回條）
3. 支援 PDF/圖片附件（單檔 10MB）
4. 顯示系統通知
5. 訊息歷史可依關鍵字與日期範圍搜尋

## 實作範圍

1. 新增買家溝通中心頁面（Client Component）
2. 以既有 `messageService` 當資料來源，採 10 秒輪詢模擬即時更新
3. 新增純函式工具：
   - 附件驗證（類型與大小）
   - 訊息關鍵字/日期過濾
   - 已讀回條文案格式化
4. 已簽約買家儀表板新增「前往溝通中心」入口

## 非範圍（本次不做）

1. 真實檔案上傳與儲存（目前使用 mock attachment URL）
2. WebSocket/SSE 真即時推送（暫用 polling）
3. 兩年以上歷史訊息封存策略（僅保留查詢介面）

## 驗收對照

1. 即時文字訊息往來：`messageService` + composer 可送出與回覆
2. 已讀/未讀狀態：訊息列表與詳情顯示回條
3. 附件支援：允許 PDF/JPG/PNG/WEBP，超過 10MB 或不支援格式會阻擋
4. 系統通知：頁面固定通知區塊顯示提醒
5. 歷史搜尋：關鍵字 + 起訖日期條件過濾

## 風險與後續

1. `messageService` 目前為 mock mode，需在後續切換至 Supabase 真實資料
2. 附件目前僅前端驗證，需補齊後端 MIME/大小雙重驗證與病毒掃描
3. 需再補真實帳號登入流程下的 E2E（含已讀狀態同步）
