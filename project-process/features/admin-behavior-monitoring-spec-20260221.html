一、功能描述

超級管理員可透過此功能即時監控平台上所有使用者的行為軌跡，包含頁面瀏覽、操作紀錄、異常行為偵測，並生成統計報表供管理決策使用。

二、驗收標準 (Acceptance Criteria)

  • 系統需記錄所有使用者的頁面訪問紀錄，包含時間戳、IP 位址、使用者 ID、頁面路徑
  • 提供每日 / 每週 / 每月流量統計報表，以圖表形式呈現（折線圖、長條圖）
  • 異常行為需自動標記並通知管理員（如短時間內大量請求、異地登入）
  • 日誌保存期限至少 90 天，超過後自動封存至冷儲存；可手動查詢封存資料
  • 需支援依使用者、日期範圍、頁面路徑、動作類型的多條件篩選搜尋

四、資料模型

欄位類型說明
idUUID紀錄唯一識別碼
user_idUUID (FK)使用者 ID（可為 NULL 對應未登入訪客）
page_pathVARCHAR(500)被訪問的頁面路徑
action_typeENUMPAGE_VIEW / CLICK / FORM_SUBMIT / API_CALL
ip_addressINET使用者 IP（加密儲存）
user_agentTEXT瀏覽器與裝置資訊
created_atTIMESTAMPTZ事件發生時間
is_anomalyBOOLEAN是否被標記為異常行為
metadataJSONB額外擴充資訊

五、技術實作方向

前端追蹤：透過 Next.js middleware 或自訂 Analytics Hook，在每個頁面導航時觸發行為記錄 API。
後端儲存：Supabase behavior_logs 資料表 + RLS 僅允許 super_admin 角色讀取。
異常偵測：設定規則引擎（如：同一 IP 1分鐘內超過100次請求 → 標記異常並寫入 security_alerts 表）。
