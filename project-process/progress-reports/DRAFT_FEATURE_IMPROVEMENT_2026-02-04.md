## 🐛 問題描述

### 用戶回饋

> "儲存草稿，讀取草稿的功能有問題，不應該只存到最近一次？應該是用物件標題作為預設的存檔檔名，讓user讀取時可以選擇多個物件繼續編輯"

### 原本的問題

1. ❌ **預設檔名不直觀**
   ```
   舊檔名: "草稿 2026/2/4 下午3:28"
   問題: 無法快速識別是哪個物件的草稿
   ```

2. ❌ **需要手動輸入檔名**
   ```
   用戶體驗: 每次儲存都要想檔名，很麻煩
   ```

3. ✅ **多個草稿支援** (原本就有，但 UI 不明顯)
   ```
   功能: 最多保留 10 個草稿
   狀態: 已實作，但用戶不清楚
   ```

## ✅ 解決方案

### 1. 自動使用物件標題作為預設檔名

#### 實作邏輯

```typescript
const handleSaveDraft = async (customName?: string) => {
  const formData = watch()

  // 自動生成檔名
  const title = formData.title || '未命名物件'
  const type = formData.type === 'rental' ? '出租' : '出售'
  const defaultName = `${title} - ${type}`

  // 優先順序: 自訂名稱 > 預設名稱
  const finalName = customName || draftName.trim() || defaultName

  saveDraft(formData, finalName)
}
```

#### 範例

| 物件資料 | 生成的檔名 |
|---------|-----------|
| 標題: "台北市大安區精緻公寓"<br>類型: 出租 | `台北市大安區精緻公寓 - 出租` |
| 標題: "信義區豪宅"<br>類型: 出售 | `信義區豪宅 - 出售` |
| 標題: 未填寫<br>類型: 出租 | `未命名物件 - 出租` |

## 🔧 技術實作細節

### 檔名生成邏輯

```typescript
// 優先順序
const finalName =
  customName ||           // 1. 用戶自訂名稱（最高優先）
  draftName.trim() ||     // 2. Drawer 輸入框的名稱
  defaultName             // 3. 自動生成的預設名稱

// 預設名稱格式
const defaultName = `${title} - ${type}`
// 範例: "台北市大安區精緻公寓 - 出租"
```

### UI 改進

#### 1. 預設檔名預覽
```typescript
{watch('title') && (
  <div className="text-xs text-[#999999]">
    預設檔名: {watch('title')} - {watch('type') === 'rental' ? '出租' : '出售'}
  </div>
)}
```

#### 2. 動態 Placeholder
```typescript
<Input
  placeholder={
    watch('title')
      ? `預設: ${watch('title')} - ${watch('type') === 'rental' ? '出租' : '出售'}`
      : '輸入自訂名稱（選填）'
  }
  value={draftName}
  onChange={(e) => setDraftName(e.target.value)}
/>
```

#### 3. 草稿資訊顯示
```typescript
{draftData.address && (
  <p className="text-xs text-[#999999] truncate">
    📍 {draftData.address}
  </p>
)}
{draftData.price && (
  <p className="text-xs text-[#999999]">
    💰 NT$ {draftData.price.toLocaleString()}
    {draftData.type === 'rental' ? '/月' : ''}
  </p>
)}
```
