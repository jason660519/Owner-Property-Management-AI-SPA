## 🎯 更新欄位

請更新或新增以下欄位：

| 欄位 | 說明 | 格式要求 |
|------|------|----------|
| `id` | 任務編號 | 格式: `TASK-YYYYMMDD-XXX` (如: `TASK-20260214-001`) |
| `category` | 工作分類 | 如: `部署優化`、`日誌系統`、`文件撰寫` |
| `feature` | 功能與說明 | 簡述完成的功能 (1-2 句話) |
| `acceptanceCriteria` | 完成標準 | 列出驗收標準 (條列式) |
| `devProgress` | 開發進度 | 百分比: `0%`, `50%`, `100%` |
| `testProgress` | 測試進度 | 百分比: `0%`, `50%`, `100%` |
| `devLog` | 開發日誌 | 詳細記錄 (見下方格式) |
| `lastModified` | 最後修改 | 格式: `Claude Sonnet 4.5 - 2026-02-14 HH:mm` |

## 🔄 處理流程

1. **讀取現有資料**
   - 讀取 `project-process/roadmap.js`
   - 解析 `window.ROADMAP_DATA` 陣列

2. **任務識別**
   - **若我有指定編號** (如: `TASK-20260214-001`)  
     → 找到該編號，直接更新內容
   - **若我未指定編號**  
     → 自動產生新編號 (取最後一筆 +1)，在陣列末尾新增

3. **整理今日工作**
   - 根據今天的 Git commits、討論內容、修改的檔案
   - 彙整為結構化的開發日誌

4. **寫入資料**
   - 更新或新增至 `window.ROADMAP_DATA`
   - 保持原有格式與縮排

5. **回應確認**
   - 列出更新的編號
   - 摘要說明更新內容

## 🚨 注意事項

- 確保 JSON 格式正確（注意逗號、引號、跳脫字元）

- 時間戳記使用當前時間（台灣時區 UTC+8）
- Git commit hash 請使用短版本 (前 7 碼)
