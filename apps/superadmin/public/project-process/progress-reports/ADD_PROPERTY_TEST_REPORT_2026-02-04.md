## 🎯 草稿功能完整說明

### 1. 草稿儲存在哪裡？

**答案**: 瀏覽器的 LocalStorage

```javascript
// 儲存位置
localStorage.getItem('property_form_drafts')

// 資料結構
[
  {
    "id": "1738665600000",
    "name": "台北市大安區精緻公寓 - 出租",
    "savedAt": "2026-02-04T10:00:00.000Z",
    "data": {
      "title": "台北市大安區精緻公寓",
      "address": "台北市大安區和平東路三段123號",
      "type": "rental",
      "price": 30000,
      // ... 其他表單資料
      "formKey": "property_add_form"
    }
  },
  // ... 最多 10 個草稿
]
```

### 2. 可以存幾個檔案？

**答案**: 最多 **10 個**草稿

- 當超過 10 個時，最舊的草稿會被自動刪除
- 新的草稿總是加在最前面（最新的在最上面）
- 計數顯示：「已儲存的草稿 (3/10)」

### 3. 如何儲存草稿？

#### 方式 1: 快速儲存（使用預設檔名）

```
1. 填寫物件標題（例如：「台北市大安區精緻公寓」）
2. 選擇類型（出租/出售）
3. 點擊「儲存草稿」按鈕（在「讀取草稿」旁邊）
4. 系統自動生成檔名：「台北市大安區精緻公寓 - 出租」
```

**優點**:
- ✅ 快速，不需要輸入檔名
- ✅ 檔名自動包含物件資訊，容易識別

#### 方式 2: 自訂檔名

```
1. 填寫物件資料
2. 點擊「讀取草稿」開啟 Drawer
3. 看到預設檔名預覽
4. 輸入自訂名稱（例如：「VIP客戶-王先生物件」）
5. 點擊「儲存」
```

**優點**:
- ✅ 完全自訂檔名
- ✅ 可以加入客戶名稱、備註等資訊

### 4. 如何讀取草稿？

```
1. 點擊「讀取草稿」按鈕
2. 開啟草稿管理 Drawer
3. 看到草稿列表，每個草稿顯示：
   - 📝 草稿名稱
   - 📍 物件地址
   - 💰 價格（含出租/出售標記）
   - 🕐 儲存時間
4. 點擊想要的草稿的「載入」按鈕
5. 表單自動填入草稿資料
```

### 5. 草稿包含哪些資料？

草稿會儲存**整個表單**的所有資料：

| 步驟 | 儲存的欄位 |
|-----|-----------|
| **Step 1** | 標題、地址、類型、價格 |
| **Step 2** | 所有權人、聯絡地址、建號、地號 |
| **Step 3** | 主建物面積、附屬建物（多筆）、車位（多筆）、公設面積 |
| **Step 4** | 房間數、衛浴數、樓層、總樓層、描述 |
| **Step 5** | 照片（⚠️ 照片 URL 保留，但 File 物件會被移除） |

**⚠️ 照片限制**:
- 照片的 `blob:` URL 在頁面重新載入後會失效
- 載入草稿後，照片預覽會消失，需要重新上傳
- 這是瀏覽器安全限制，無法繞過

## 🐛 已知問題

### 1. 照片在草稿中的限制 ⚠️

**問題**: 照片的 File 物件無法序列化到 LocalStorage

**影響**:
- 載入草稿後，照片預覽會消失
- 需要重新上傳照片

**解決方案** (已實作):
- ✅ 儲存時移除 File 物件（只保留 URL）
- ✅ 載入時 file 設為 null
- ✅ 不會造成錯誤，只是照片需要重新上傳

**未來改進** (可選):
- 將照片轉為 Base64 儲存（會增加 LocalStorage 使用量）
- 上傳到臨時儲存（需要後端支援）

### 2. LocalStorage 容量限制 ⚠️

**問題**: LocalStorage 通常只有 5-10MB

**影響**:
- 儲存大量草稿可能達到容量限制
- 儲存帶有大量資料的草稿可能失敗

**解決方案** (已實作):
- ✅ 限制最多 10 個草稿
- ✅ 捕獲 QuotaExceededError 並顯示錯誤訊息

## 📝 用戶常見問題 (FAQ)

### Q1: 草稿會過期嗎？

**A**: 不會。草稿永久儲存在瀏覽器的 LocalStorage 中，除非：
- 用戶手動刪除
- 清除瀏覽器資料
- 達到 10 個上限被自動刪除（最舊的）

### Q2: 可以在不同電腦看到草稿嗎？

**A**: 不行。草稿儲存在瀏覽器的 LocalStorage，只存在於當前電腦的當前瀏覽器中。

### Q3: 切換瀏覽器會失去草稿嗎？

**A**: 是的。Chrome 的草稿無法在 Firefox 中看到，因為 LocalStorage 是瀏覽器隔離的。

### Q4: 無痕模式可以使用草稿嗎？

**A**: 可以，但關閉無痕視窗後草稿會消失。

### Q5: 草稿會備份到雲端嗎？

**A**: 目前不會。這是未來可能的功能（需要後端支援）。
