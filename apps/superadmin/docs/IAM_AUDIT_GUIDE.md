# IAM Audit Report 使用說明

## 1. 功能概述

IAM Audit Report（權限審計報告）提供系統管理員即時的權限狀態快照與歷史異動追蹤功能。此模組整合了現有使用者、角色與群組資料，並模擬異動紀錄以供稽核參考。

**存取路徑**: `Superadmin Dashboard` > 左側選單 > `IAM Audit Report`

---

## 2. 主要功能

### 2.1 儀表板統計
頁面頂部顯示四個關鍵指標：
- **總用戶數／總人數／目前在線人數**: 
    - **總用戶數**：系統中所有註冊帳號的數量。
    - **總人數**：實際自然人數量（已排除同一帳號多重角色的重複計算）。
    - **目前在線人數**：過去 24 小時內有登入紀錄的活躍使用者數量。
- **群組數**: 定義的 IAM 群組總數。
- **自定義角色數**: 系統可用的自定義角色總數。
- **今日異動數**: 24小時內的權限變更操作次數。

### 2.2 詳細異動記錄 (Audit Logs)
表格列出所有的權限操作紀錄，包含：
- **時間戳記**: 操作發生的時間。
- **操作者**: 執行該動作的管理員或系統程序。
- **類型**: 變更對象的類型 (USER, ROLE, GROUP)。
- **目標對象**: 受影響的帳號或資源名稱。
- **變更內容**: 執行的動作 (如 UPDATE_ROLE)。
- **詳細說明**: 變更的具體內容。
- **狀態**: 操作成功或失敗。

### 2.3 搜尋與篩選
- **關鍵字搜尋**: 可針對使用者名稱、操作者或動作類型進行模糊搜尋。
- **類型篩選**: 點擊 `USER`, `ROLE`, `GROUP` 標籤可快速篩選特定類型的紀錄。

### 2.4 資料更新
- **自動刷新**: 系統每 **5 分鐘** 自動重新獲取最新數據。
- **手動刷新**: 點擊右上角的「刷新」按鈕可立即更新。

### 2.5 匯出報告
支援將當前篩選後的紀錄匯出：
- **匯出 CSV**: 下載 `.csv` 格式檔案，可於 Excel 開啟。
- **匯出 PDF**: (目前為預留功能，即將推出)。

## 3. 技術說明

### API 端點
- `GET /api/iam/audit`: 獲取審計資料。
    - 回傳：`{ snapshot: {...}, stats: {...}, logs: [...] }`
    - 邏輯：
        1. 讀取 Supabase 真實的 `auth.users`, `iam_roles`, `iam_groups` 狀態。
        2. 計算即時統計數據，包含依據 Email 進行去重計算總人數，以及依據 `last_sign_in_at` 計算活躍人數。
        3. 根據現有用戶生成模擬的歷史異動紀錄 (因目前尚未啟用資料庫層級的 Audit Log Trigger)。

### 注意事項
- 目前的「異動記錄」是基於現有狀態回推的模擬數據，用於展示 UI 與報表功能。若需真實的歷史追溯，需在資料庫層級啟用 Trigger 並建立 `audit_logs` 資料表。
