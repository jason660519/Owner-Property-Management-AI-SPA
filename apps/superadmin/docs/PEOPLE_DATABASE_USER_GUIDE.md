# 尋人資料庫使用說明（Superadmin）

本文件提供超級管理員在 `尋人資料庫` 頁面的實際操作流程，涵蓋：

- 搜尋人員資料
- 匯入新資料
- 管理資料來源

---

## 1. 入口與頁面結構

### 1.1 入口位置

從 Superadmin 側邊欄點擊：

- `尋人資料庫`

對應路由：

- `/superadmin/settings/people-database`

### 1.2 頁面區塊

目前為單頁整合工作區，主要分成三個可展開區塊：

1. `搜尋`
2. `匯入`
3. `資料來源`

頁面上方顯示統計資訊（總筆數、已索引、資料來源、平均品質），方便先看整體健康度。

---

## 2. 搜尋流程（建議先學會）

### 2.1 基本操作

1. 展開 `搜尋` 區塊
2. 在搜尋框輸入關鍵字（姓名、電話、身分證字號）
3. 按 `搜尋`
4. 查看結果列表

### 2.2 資料集範圍（左側樹狀面板）

- 左側 `資料集樹狀面板` 可勾選要查的資料來源
- 若未勾選任何資料集，系統預設為「搜尋全部資料集」

建議：

- 要快速找人：先用「全部資料集」
- 要做精準排查：只勾選特定資料來源

### 2.3 結果呈現模式

搜尋區有兩種結果模式：

- `依 person 聚合`：同一個人整合顯示，適合查重與來源比對
- `依 record 展開`：逐筆明細，適合檢查原始資料

### 2.4 篩選與追溯

- 可用 `品質分數` 篩選高/中/低品質
- 每筆結果會顯示 `資料來源 badge` 與原始檔案資訊
- 點姓名可進入個人詳情頁，繼續看關聯與來源

---

## 3. 匯入流程（CSV/TXT/XLSX/PDF）

### 3.1 支援格式與限制

- 支援：`.csv`、`.txt`、`.xlsx`、`.pdf`
- 可單檔或整個資料夾匯入
- 系統有單檔大小、總大小、檔案數量限制（以頁面提示為準）

### 3.2 操作步驟

1. 展開 `匯入` 區塊
2. 拖放檔案，或點選 `選擇檔案 / 選擇整個資料夾`
3. 等待系統產生欄位預覽
4. 完成欄位映射（至少要映射 `姓名`）
5. 填寫批次設定：
   - `資料集根目錄`（必填）
   - `子路徑`（選填）
   - `舊版扁平標籤`（選填）
   - `批次標籤`（選填）
6. 點 `開始匯入`

### 3.3 匯入後狀態

- 小檔案：可能同步完成並回傳 batch 資訊
- 大檔案：會進背景佇列（job）處理
- 可回到搜尋/資料來源區，確認資料是否可見且標籤正確

---

## 4. 資料來源管理流程

### 4.1 功能目的

`資料來源` 區塊用來管理 dataset 的可讀性與可用性：

- 改顯示名稱
- 收藏/取消收藏
- 啟用/停用
- 批次操作多筆來源

### 4.2 常見操作

1. 展開 `資料來源` 區塊
2. 先用關鍵字篩選路徑/名稱
3. 對單筆來源執行：
   - 點名稱改名
   - 點星號切收藏
   - 點眼睛切啟用
4. 要一次改多筆時，先勾選後用上方批次工具列

---

## 5. 建議日常作業順序

建議採用以下順序降低錯誤率：

1. 先在 `匯入` 完成資料上傳與映射
2. 到 `資料來源` 調整名稱、收藏與啟用狀態
3. 回 `搜尋` 用關鍵字與資料集範圍驗證結果
4. 若資料異常，再回匯入檢查欄位映射與 dataset 設定

## 6. 常見問題（FAQ）

### Q1. 搜尋不到剛匯入的資料？

請依序確認：

1. 是否在 `資料來源` 區塊被停用
2. 搜尋時是否限制在錯誤的資料集範圍
3. 匯入是否仍在背景佇列處理中

### Q2. `開始匯入` 按鈕為什麼不能按？

最常見原因：

- 尚未映射 `姓名` 欄位
- `資料集根目錄` 尚未填寫（必填）

### Q3. 何時使用「依 person 聚合」？

- 要看同一人跨來源整併結果：用 `依 person 聚合`
- 要稽核原始逐筆資料：用 `依 record 展開`
