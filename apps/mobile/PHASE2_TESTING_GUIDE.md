## 🚀 快速啟動

### 1. 安裝依賴

```bash
cd apps/mobile
npm install
```

### 2. 啟動 Supabase（如果未啟動）

```bash
cd ../..
supabase start
```

### 3. 啟動 Expo

```bash
cd apps/mobile
npm start
```

### 4. 在設備上測試

**重要**：相機功能必須在實體手機上測試，模擬器不支援相機。

- **iOS**: 掃描 QR Code 或使用 Expo Go App
- **Android**: 掃描 QR Code 或使用 Expo Go App

## 🧪 Phase 2 功能測試清單

### ✅ 1. 相機拍攝功能

#### 測試步驟

1. 進入「文件管理」頁面
2. 點擊「拍攝照片」按鈕
3. 授予相機權限
4. 拍攝一張文件照片
5. 確認照片被裁剪為 4:3 縱橫比
6. 確認照片自動上傳

#### 預期結果

- ✅ 相機啟動正常
- ✅ 可切換前/後鏡頭（部分設備）
- ✅ 拍攝後顯示預覽
- ✅ 照片自動壓縮（< 2MB）
- ✅ 上傳成功後列表自動刷新
- ✅ 新文件顯示在列表頂部

#### 驗證要點

```
檢查上傳的照片：
1. 打開 Supabase Dashboard
2. 進入 Storage > property-documents
3. 確認檔案大小 < 2MB
4. 確認檔案名稱格式：photo_[timestamp].jpg
```

### ✅ 3. 刪除確認對話框

#### 測試步驟

1. 點擊任一文件卡片右側的「⋮」選單按鈕
2. 觀察對話框內容
3. 測試「取消」按鈕
4. 再次點擊「⋮」選單按鈕
5. 測試「刪除」按鈕

#### 預期結果

**對話框顯示**:
- ✅ 顯示警告圖標（紅色三角形）
- ✅ 標題：「確認刪除文件？」
- ✅ 顯示文件名稱
- ✅ 顯示文件類型（中文標籤）
- ✅ 警告訊息：「此操作無法復原...」
- ✅ 兩個按鈕：「取消」與「刪除」

**操作行為**:
- ✅ 點擊「取消」關閉對話框
- ✅ 點擊「刪除」後顯示載入動畫
- ✅ 刪除成功後顯示成功提示
- ✅ 列表自動刷新，已刪除文件消失
- ✅ Supabase Storage 中的文件被刪除
- ✅ 資料庫記錄被刪除

#### 驗證要點


## 🔧 故障排除

### 相機無法啟動

**原因**: 權限未授予
**解決**:
```
iOS: 設定 > 隱私權 > 相機 > Expo Go
Android: 設定 > 應用程式 > Expo > 權限 > 相機
```

### 縮圖無法顯示

**原因**: Supabase Storage 權限問題
**解決**:
```sql
-- 確認 storage.objects 有 SELECT 權限
-- 檢查 property-documents bucket 是否為 public
```

### 刪除失敗

**原因**: RLS 政策限制
**解決**:
```sql
-- 確認有 DELETE 權限
-- 檢查 owner_id 是否匹配當前用戶
```

## 🎓 測試技巧

### 1. 快速重置測試環境

```bash
# 清空 Supabase Storage
supabase storage empty property-documents

# 清空資料庫記錄
# 在 Supabase SQL Editor 執行：
DELETE FROM property_documents WHERE owner_id = 'your-user-id';
```

### 2. 使用 React Native Debugger

```bash
# 安裝
brew install --cask react-native-debugger

# 啟動
open "rndebugger://set-debugger-loc?host=localhost&port=8081"
```

### 3. 查看 Expo Logs

```bash
# 啟動時添加 --dev-client 參數
npm start -- --dev-client

# 或使用 tunnel 模式
npm start -- --tunnel
```
